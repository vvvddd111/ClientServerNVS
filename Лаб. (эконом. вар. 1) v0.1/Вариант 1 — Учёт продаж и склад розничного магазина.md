# ✅ Проект №1: Учёт продаж и склад розничного магазина

## 🎯 Цель
Автоматизировать учёт товаров на складе, продаж и базовую экономическую аналитику для небольшой розничной сети (1–5 магазинов).

## 📌 Описание — заказчик хочет
> «У нас три магазина одежды. Сейчас остатки считаем в Excel, который два продавца правят одновременно — потом расхождения находим только на инвентаризации. Хочу видеть в одном месте: сколько товара осталось на каждой точке, что продаётся лучше всего, а что зависло на складе и его пора уценивать. И чтобы бухгалтер раз в месяц мог выгрузить отчёт по выручке без моей помощи.»

Система ведёт каталог товаров с привязкой к категории и поставщику, фиксирует продажи по магазинам, автоматически списывает остаток при продаже и предупреждает, когда товар заканчивается. Отдельно — аналитика: топ товаров по продажам, «зависшие» позиции (ABC-анализ), выручка по периодам.

## 🌐 API

- `POST /api/products` — добавить товар в каталог
- `GET /api/products?category=&supplier=&lowStock=true` — каталог с фильтрами, в т.ч. «заканчивается на складе»
- `POST /api/sales` — зарегистрировать продажу (списывает остаток транзакционно, откат при нехватке товара)
- `GET /api/sales?storeId=&from=&to=` — история продаж с пагинацией
- `GET /api/analytics/top-products?period=month` — топ-10 товаров по выручке
- `GET /api/analytics/abc` — ABC-анализ товаров
- `GET /api/reports/revenue/export?format=xlsx` — выгрузка отчёта по выручке (Excel, тепловая карта по категориям и времени)

## 🚀 Доп
